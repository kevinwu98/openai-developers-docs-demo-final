# OpenAI Developers

Private focused Mintlify demo generated from the public Markdown corpus at https://developers.openai.com/api/docs/llms.txt. The selected pages are local MDX files and the repository is ready for Mintlify and GT.

## Run locally

```bash
npx mint@latest dev
```

## Connect to Mintlify

Install or update the Mintlify GitHub App so it can access this private repository, then select the `main` branch and repository root in Mintlify's Git settings. The factory ran strict `mint validate` against this exact workspace before publication.

See `RECREATION_REPORT.md` for provenance and scope.
